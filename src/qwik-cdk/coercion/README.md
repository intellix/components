# @angular-community/qwik-cdk/coercion

Qwik port of [@angular/cdk/coercion](https://github.com/angular/components/tree/main/src/cdk/coercion).
Exports the value-coercion helpers from CDK verbatim: `coerceBooleanProperty`, `coerceNumberProperty`, `coerceArray`, `coerceStringArray`, `coerceCssPixelValue`, `coerceElement`.
Pure functions; no framework dependency. See SYNC.md for porting deviations.
