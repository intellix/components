# @angular-community/qwik-cdk/bidi

Qwik port of [@angular/cdk/bidi](https://github.com/angular/components/tree/main/src/cdk/bidi).
Exports `Directionality` (signal-backed `value: 'ltr' | 'rtl'`), `DIRECTIONALITY` context + `useDirectionality`, `isDirection`, and the `Direction` type.
See SYNC.md for porting deviations.
