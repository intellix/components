# @angular-community/qwik-cdk/portal

Qwik port of [@angular/cdk/portal](https://github.com/angular/components/tree/main/src/cdk/portal).
Exports the collapsed `Portal<P> = { Component, props }` type and `<CdkPortalOutlet>` component for rendering an arbitrary Qwik component into a host element.
The Angular `ComponentPortal`/`TemplatePortal`/`DomPortal` and `DomPortalOutlet` abstractions are dropped (no Qwik analogue). See SYNC.md for porting deviations.
