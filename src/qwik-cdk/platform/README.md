# @angular-community/qwik-cdk/platform

Qwik port of [@angular/cdk/platform](https://github.com/angular/components/tree/main/src/cdk/platform).
Exports `Platform` (browser feature flags), `PLATFORM` context + `usePlatform`, `isBrowser`, and feature helpers (`getSupportedInputTypes`, `supportsPassiveEventListeners`, `supportsScrollBehavior`, `_getShadowRoot`, `_getEventTarget`, `_supportsShadowDom`, `_isTestEnvironment`).
See SYNC.md for porting deviations.
