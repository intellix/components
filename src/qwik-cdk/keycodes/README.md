# @angular-community/qwik-cdk/keycodes

Qwik port of [@angular/cdk/keycodes](https://github.com/angular/components/tree/main/src/cdk/keycodes).
Exports the `KeyCode` numeric constants (`ESCAPE`, `ENTER`, `TAB`, etc.) and `hasModifierKey` helper.
Pure constants; no framework dependency. See SYNC.md for porting deviations.
